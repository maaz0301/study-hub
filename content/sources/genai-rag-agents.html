1. The big picture in one minute

An LLM is smart but only knows what it read in training. So we give it an open book (RAG), and sometimes hands to act (agents). Everything else in the guide is a way to make those two things better, cheaper or safer.

A. Prepare the book (done once, repeated when documents change)

1. DocumentsPDFs, web pages, databases
2. Chunkcut into small passages
3. Embedeach passage becomes numbers (meaning)
4. Storein a vector database with labels (metadata)

B. Answer a question (every time, RAG)

1. Questionrewrite it if it is vague
2. Searchfind the closest passages (meaning + keywords)
3. Re-rankkeep the best 3 to 8
4. LLM readsquestion + passages: 'answer only from these'
5. Answerwith citations, or 'I don't know'

C. Let it act (agent = the LLM in a loop)

1. Thinkwhat should I do next?
2. Use a toolsearch docs, run SQL, send email
3. Observeread the tool result
4. Repeat or stopfinal answer, step limit, or ask a human
Three questions that decide almost everything: Does the AI need knowledge? use RAG. Does it need to act? use tools, then maybe an agent. Is it risky? add limits, approvals and evaluation.

Practice checklist

Project ideas for your CV

  • Document Q&A bot with citations, hybrid search and a re-ranker, plus an evaluation report.
  • Multi-tenant knowledge base (Pinecone namespaces or pgvector tenant filters) with a test proving no cross-tenant leakage.
  • Support agent with RAG, an order lookup tool, a refund tool with approval, and a trace view.
  • Self-correcting RAG as a graph (grade documents, rewrite query, check answer) with a loop limit.
  • Research agent that plans, searches in parallel, writes notes with sources, and verifies claims.

Interview tips

  • Answer in three parts: the idea in one sentence, how it works, the trade-off.
  • Always say how you would evaluate it: it shows production thinking.
  • Admit what you do not know and say how you would find out. Do not invent API details.
  • Bring one real example with numbers, such as "recall@5 went from 62 to 81 percent after adding a re-ranker".
